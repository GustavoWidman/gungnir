Regenerate from the scenario directory with the Python of the python language's toolchain: `python3 gen/gen.py cases` rewrites examples/ and hidden/ (committed), and `python3 gen/gen.py workloads` writes workloads/ (gitignored, large). Seeds are fixed. Expected outputs come from `reference/python`. The workloads' SHA-256 digests are committed in `workloads.sha256`; check a regeneration with `sha256sum -c workloads.sha256` from the `workloads/` directory.

The `knuth-*` cases divide numbers built so that long division in a given limb base (10^9, 2^32, 2^64, and a mix of others) estimates a quotient limb one too large and must add the divisor back, or estimates a full limb and must clamp it. Most huge operands are written as short power expressions, which keeps hidden/ small while the values reach the spec's 200,000-digit bound.
