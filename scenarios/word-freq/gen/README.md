Regenerate from the scenario directory with Python 3.14: `python3 gen/gen.py cases` rewrites examples/ and hidden/ (committed), and `python3 gen/gen.py workloads` writes workloads/ (gitignored, large). Seeds are fixed. Expected outputs come from `reference/python`. The workloads' SHA-256 digests are committed in `workloads.sha256`; check a regeneration with `sha256sum -c workloads.sha256` from the `workloads/` directory.
