Regenerate from the scenario directory with the Python of the python language's toolchain: `python3 gen/gen.py cases` rewrites examples/ and hidden/ (committed), and `python3 gen/gen.py workloads` writes workloads/ (gitignored; each is a short program that runs tens of millions of instructions). Seeds are fixed. Expected outputs come from `reference/python`, and every hand-written case also states its expected output, so `cases` fails when the reference disagrees with it. The workloads' SHA-256 digests are committed in `workloads.sha256`; check a regeneration with `sha256sum -c workloads.sha256` from the `workloads/` directory.
