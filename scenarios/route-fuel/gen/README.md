Regenerate from the scenario directory with the Python of the python language's toolchain: `python3 gen/gen.py cases` rewrites examples/ and hidden/ (committed), and `python3 gen/gen.py workloads` writes workloads/ (gitignored, large). Seeds are fixed. Expected outputs come from `reference/python`. The workloads' SHA-256 digests are committed in `workloads.sha256`, which `python3 gen/gen.py workloads` rewrites, so a regeneration that reproduces the workloads leaves it unchanged: check with `git diff --exit-code workloads.sha256`.
