Regenerate from the scenario directory with the Python of the python language's toolchain: `python3 gen/gen.py cases` rewrites examples/ and hidden/ (committed), and `python3 gen/gen.py workloads` writes workloads/ (gitignored, large). Seeds are fixed. Expected outputs come from `reference/python`, and random cases drop any query whose output block exceeds a byte budget, which also depends on that reference. The generator asserts the input constraints of spec.md (query length and bytes, document size, nesting depth) for every case it writes. The workloads' SHA-256 digests are committed in `workloads.sha256`; check a regeneration with `sha256sum -c workloads.sha256` from the `workloads/` directory.
